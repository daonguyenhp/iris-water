# Security Policy

## Supported Versions

As this project is in its early stages of development (Version 0/MVP), we currently only provide security updates for the latest active version.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not** open a public issue. Publicly disclosing a vulnerability before it is fixed puts the project at risk.

Instead, please report it privately by emailing us at: **[email@example.com]**

**What to expect:**
* We will acknowledge receipt of your email within 48 hours.
* If the vulnerability is accepted, we will work on releasing a patch as quickly as possible.
* We will notify you once the issue has been resolved and the patch is released. Thank you for helping keep this project secure!
